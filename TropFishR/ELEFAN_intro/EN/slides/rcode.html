Running it in R with TropFishR

install.packages("TropFishR")
library(TropFishR)
data(synLFQ7)              # synthetic data with known parameters

res <- ELEFAN_GA(synLFQ7, MA = 5, seasonalised = TRUE,
       low_par = list(Linf = 100, K = 0.05, t_anchor = 0, C = 0, ts = 0),
       up_par  = list(Linf = 140, K = 0.6,  t_anchor = 1, C = 1, ts = 1),
       popSize = 60, maxiter = 50, plot = TRUE)

res$par                    # estimated L∞, K, t_anchor, C, ts
res$Rn_max                 # the score Rn

MA: moving-average width (classes) · low_par / up_par: search range · plot = TRUE: draw curves on the data
